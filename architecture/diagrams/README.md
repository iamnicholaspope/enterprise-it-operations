# PlantUML Diagram Library

This directory is the source of truth for architecture diagrams.

## Naming Convention

Use:

`<number>-<short-description>.puml`

Examples:

- `01-enterprise-overview.puml`
- `01-network-topology.puml`
- `01-ad-replication.puml`

## Diagram Standards

Each diagram should include:

- Title
- Business or technical purpose
- Major systems/components
- Directional relationships where useful
- Trust/network boundaries when relevant
- Notes for assumptions or constraints

Avoid putting passwords, secrets, tokens, private keys, or real production credentials in diagrams.
