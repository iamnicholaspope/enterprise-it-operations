# Enterprise IT Operations Project

This repository documents the architecture and implementation of a hypothetical 26-employee hybrid business environment with 21 office-based and 5 remote employees.

## Architecture Diagrams

PlantUML source files are stored under:

`architecture/diagrams/`

The diagram structure is organized by domain so the environment can grow without becoming difficult to maintain.

## Recommended PlantUML Workflow

1. Edit the `.puml` source file.
2. Render locally using PlantUML or a compatible IDE/plugin.
3. Export PNG/SVG files beside the source or into an `exports/` folder if desired.
4. Keep the `.puml` source under Git version control.
